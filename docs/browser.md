# 内置浏览器

JO-AIClient 内置一个可独立使用的浏览器，同时允许助手在获得授权后操作网页。浏览器标签归属于当前会话，切换会话不会丢失。

## 打开方式

- 手机端：从聊天附件菜单或工具菜单打开浏览器；输入网址后开始浏览。
- 桌面端：从聊天工具菜单打开浏览器侧栏；侧栏可调整宽度，也可以展开为完整浏览器页面。
- 浏览器会打开上次使用的标签；没有标签时显示起始页。

## 标签与会话

- 每个会话有自己的标签集合，标签不会混到其他会话。
- 支持新建、切换、关闭和恢复标签；关闭最后一个标签后回到起始页。
- 标签总览默认显示当前会话；可以切换到“全部标签”，按会话查看已保存的页面。
- 可以把自己的标签移动或重新打开到另一个会话；移动会保留页面状态，重新打开会创建独立标签。

## 浏览与导航

- 地址栏支持输入网址或搜索关键词。
- 支持前进、后退、刷新、停止加载和页面内查找。
- 支持选择搜索引擎、桌面版网站模式、书签编辑与搜索、按日期分组的历史记录。
- 可预览当前会话绑定工作区的 HTML 和相对资源；其他会话或工作区不可访问。
- 支持下载文件、查看下载进度、取消下载、打开已完成的文件，以及清理已下载记录。
- 支持复制当前链接、用系统浏览器打开页面，以及清除网站 Cookie、缓存和本地存储。

## 浏览器助手

- 助手需要同时获得浏览器工具权限和浏览器内的 Agent 授权，才能操作网页。
- 助手可以读取当前页面、点击、填表、滚动和按步骤执行任务；每次操作会显示在聊天时间线的页面卡片中。
- 页面卡片会显示当前步骤、页面标题、预览图和执行结果；运行中的任务可以停止。
- 人工接管会取消正在排队的操作；重新交给助手后才会继续。
- 助手不能处理需要系统级可信输入、验证码、支付确认或原生应用交互的页面；这类情况需要用户手动完成。

## 外观与限制

- 浏览器支持独立的材质样式和桌面/移动布局，不改变聊天页面的外观设置。
- 网页登录状态由系统 WebView 管理；部分网站会限制嵌入式浏览器登录，遇到时可以用系统浏览器打开。
- 下载、上传、登录和网页脚本行为最终取决于系统 WebView 和目标网站，不能保证与桌面浏览器完全一致。
- 清除网站数据会退出已登录网站；该操作不会删除聊天记录或工作区文件。

> 移动端工具栏会随页面滚动收起为地址胶囊，返回顶部或点击后展开；桌面端标签页位于地址栏上方。
